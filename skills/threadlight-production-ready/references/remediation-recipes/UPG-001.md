## Target file
N/A — this fix runs the threadlight `threadlight-upgrade` leg. UPG-001 is must-fix when the upgrade leg detects a stale entry in the compatibility matrix — a model or dependency pin whose review window has lapsed or which drifted from the latest supported version. Remediation runs the leg (or its upstream fix) and refreshes `specs/upgrade-manifest.json`, whose shared envelope production-ready reads as gap evidence for `UPG-001`.

## Edit type
`sibling-skill`

## Edit recipe
1. Review the plan items in `specs/upgrade-manifest.json`; update the stale pin(s) to a supported version and refresh `last_reviewed`.
2. Re-run `threadlight-upgrade` to regenerate the compatibility plan (plan-only — the scanner never edits the project and has no `--apply`).

   ```bash
   python3 skills/threadlight-upgrade/scripts/upgrade.py \
     --project-root "${PROJECT_ROOT}" \
     --matrix-path "${COMPATIBILITY_MATRIX_FILE}" \
     --source-results-path "${SOURCE_RESULTS_FILE}" \
     --manifest-path specs/upgrade-manifest.json \
     --emit
   ```

## Verification
Re-run threadlight: `python3 scripts/production_ready.py --target-rg <RG> --target-sub <SUB>`. UPG-001 flips to `pass`/`should-fix` once `specs/upgrade-manifest.json` records it in a `complete`, fresh envelope. A `partial`, stale, or `aborted` `specs/upgrade-manifest.json` keeps `UPG-001` at `not-verified` (or `must-fix` on negative evidence) — an incomplete leg never inflates readiness.
