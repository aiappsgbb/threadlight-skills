## Edit recipe

   creates the host with `ResponsesServerOptions(resilient_background=True)`

2. Otherwise state in the README or SPEC that the agent is **"background only,
   not crash-resilient"**: a crash leaves the response non-terminal or failed, and
   the caller must not wait on it without a deadline (REL-013).
