## Target file
N/A — this fix runs the threadlight `threadlight-ground` leg. GRD-005 is must-fix when a SPEC knowledge source declared `permission_model: acl` also enables a derived artifact (`enrichments: [entity_graph]` or `[topic_graph]`). In the Foundry IQ preview, graph triples and topic indexes are separate Search indexes without document-level permissions, so every knowledge-base reader can read them and document-level ACL probes never see them. Remediation changes the SPEC declaration and refreshes `specs/ground-manifest.json`, whose shared envelope production-ready reads as gap evidence for `GRD-005`.

## Edit type
`sibling-skill`

## Edit recipe
1. Inspect `findings[].detail.derived_artifact_sources` in `specs/ground-manifest.json`.
2. Pick one fix per listed source:
   - remove the enrichment (`enrichments: [none]`) and keep the source ACL-trimmed; or
   - split the corpus so the graph is built only from a source every reader may see; or
   - when every knowledge-base reader is genuinely entitled to the whole corpus, declare `audience: uniform` with an `audience_justification` in the SPEC (the justification stays in the SPEC; the manifest records only `audience: uniform`).
3. Re-run `threadlight-ground` with the updated `sources` inventory in the evidence JSON.

   ```bash
   python3 skills/threadlight-ground/scripts/ground.py \
     --project-root "${PROJECT_ROOT}" \
     --evidence-file "${GROUND_EVIDENCE_FILE}" \
     --manifest-path specs/ground-manifest.json \
     --emit
   ```

## Verification
Re-run threadlight: `python3 scripts/production_ready.py --target-rg <RG> --target-sub <SUB>`. GRD-005 flips from `must-fix` to `pass` once `specs/ground-manifest.json` records `GRD-005: pass` in a `complete`, fresh envelope. A ground manifest produced before GRD-005 existed keeps any `must-fix` it proved, but every other `GRD-*` finding stays `not-verified` until the leg is re-run.
