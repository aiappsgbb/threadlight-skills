From demo to production: what a pilot can show today

A customer first sees a recommend-only Fast-PoC: a Foundry hosted agent that reads, cites and proposes, while a person records the decision. The same pilot then moves toward production without a rewrite. This page lists each step that exists today, how far it was proven, what is still open, and where the details are.

Live runs were on Threadlight's own returns-triage pilot in an internal nonproduction Azure subscription. They show that the path works there; they are not a certification of a customer deployment, and governance is evidenced per selected action, never for the whole agent.

Capabilities and proof

  • Proven live: run end to end on a real Azure deployment, dated and recorded.
  • Proven live, with limits: run live, but part of it used a stand-in, synthetic input or one binding; the limit is named in the row.
  • Offline only: generators and tests, no live run recorded.
