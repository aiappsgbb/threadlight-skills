Understand / before the build

Skills build agents.
Agents do the work.

A construction agent uses Threadlight skills to turn a business brief into a reviewed project. The resulting process agent handles business cases with its own skills and tools. Building it and running it are different jobs.

Start with the building block ↓

01 / A reusable unit of know-how

A skill is a playbook.
Not another agent.

It tells an agent when and how to tackle a task. Supporting code and references can make the work repeatable. The host still supplies the model, tools and permissions.

EXAMPLE / QUALIFYDeclared workload → sizing package → design input

Qualification turns an interview into sizing artifacts. It does not discover your environment or deploy an agent.

02 / From engineering to business execution

Build the process.
Then run the process.

Threadlight's construction skills are not copied wholesale into the business agent. The reviewed process determines that agent's own skills, tool contracts and runtime route.

What actually loads the skills?
Copilot SDK route
The shipped adapter supplies skill_directories when it creates a session, alongside host instructions and tool configuration.
MAF agent route
The shipped adapter supplies SkillsProvider.from_paths as a context provider, alongside instructions and native tools.
Workflow route
Some processes require an explicit workflow with executors and stages. The foundation policy selects the supported runtime route; do not infer one universal implementation from the skill format.

WHERE AUTO FITS

The lifecycle planner is not the process agent.

threadlight-auto reads project evidence and decides run, skip or stop. A coding agent or supplied worker performs the stage. Manual, live and cost-bearing handoffs stay explicit; selected governance also changes the required stage order.

03 / Beyond the coding agent

The format travels.
The host determines the reach.

A compatible host can use a skill outside a coding session. Its available tools, dependencies, credentials and network access determine what can actually execute.

CONSTRUCT

Coding-agent host

Boundary

A thin authoring environment is not a deployment environment. Cloud operations need their own tooling and authorization.
