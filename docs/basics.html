First, what is
an AI agent?

An AI agent is an application that can use AI and connected tools to work through a task. Start with a familiar example: a customer wants to return an order.

See what makes those steps possible ↓

01 / Four words you will see

Different pieces.
Different responsibilities.

INTERPRETSModel
The AI component that interprets the request and proposes text or actions. It can be wrong.In our example: understand what the customer is asking.
COORDINATESAgent
The application that uses the model, instructions and tools to take steps, examine results and continue or ask for help.In our example: move the return request toward a decision.
ACCESSESTool
Callable code that reads a system or performs a permitted operation. Mentioning a tool does not connect it or grant access.In our example: retrieve the order from the order system.
GUIDESSkill
Reusable instructions for a task: when to use a procedure, what to check and when to escalate.In our example: follow the returns procedure and request the right checks.

02 / Reuse the procedure, not just the wording

A skill is reusable
know-how for the agent.

A prompt gives one request: “Check this return.” A skill supplies the procedure to reuse across requests. It is not another agent, and it does not replace the tools that access your systems.

What is actually inside a skill package?

SKILL.md is a Markdown file: a plain-text document describing when and how to use the skill. Optional scripts/, references/ and assets/ can supply code, reference material and templates. The application needs suitable tools to use them.

03 / What Threadlight adds

One assistant builds it.
Another runs your process.

A coding assistant such as GitHub Copilot uses Threadlight's engineering skills to turn your brief into a project. The resulting process agent gets its own business skills and connected tools, not a copy of the engineering playbooks.

The value is a connected path from an agreed specification to runnable code and evidence you can inspect, rather than just a generated answer. A specification is the written agreement about what the process must do and what stays human.

WHERE AUTO FITS

Who coordinates the building steps?

This orchestration—the coordination of what happens next—is supported by threadlight-auto. It is a planner: it inspects existing project files and chooses run, skip or stop. The coding assistant or an assigned worker performs the work. It is not the returns assistant, and it does not silently approve deployment or paid operations.

04 / Do I need to be a developer?

Not to shape the idea.
Engineering comes when you build.

You can describe the process, estimate usage and review the plan without writing code. A host is the app or service that runs an agent and supplies its tools. What you can do depends on that host's capabilities and your access.

PLAN WITHOUT CODING

What it needs
